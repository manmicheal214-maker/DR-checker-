How it works

  1. Paste up to 10 page URLs, one per line.
  2. Optionally enter a target domain to show only links to that domain or its subdomains.
  3. Review each link's rel attributes, filter results, and download a CSV.

Dofollow means the link's rel attribute contains none of nofollow, sponsored, or ugc. A robots nofollow directive is reported separately and does not rewrite individual link labels.

Pages that block automated requests or fail to load can be checked by pasting their HTML into the row's local fallback. Pasted HTML is parsed in your browser and is not sent to the Worker.

What do dofollow, nofollow, sponsored and UGC mean?

A link's rel attribute describes its relationship to the destination. Dofollow is common shorthand for an ordinary link whose rel value contains none of nofollow, sponsored, or ugc; there is no special rel="dofollow" value required. This checker uses that same absence-based classification.

Nofollow is a hint that the publisher does not want to imply endorsement. Sponsored identifies advertising, sponsorship, or other paid links. UGC identifies links in user-generated content, such as comments or forum posts. Multiple values can appear together in one rel attribute. These are search-engine hints, not guarantees about crawling, indexing, or rankings.

How to read the results

Each row is a link found in the HTML returned for a submitted page. Page URL is the source; Anchor is its text or image alt text; Link URL is the destination; Type is the detected rel classification; and Scope indicates internal or external relative to the source page. Enter a target domain to narrow results to that domain and its subdomains. Filters, search, and the scope selector change the displayed rows; Download CSV exports results.

A robots nofollow warning is separate from Type: it reports a detected page-level directive, not an anchor's rel value. If a page cannot be fetched, the row offers a local HTML fallback for browser-side parsing.

Manual method: inspect a link yourself

Open the source page, right-click the link, and choose Inspect to view its anchor element in DevTools. Examine the rel attribute. Alternatively, choose View Page Source and search for the destination URL or rel=. Look for the tokens nofollow, sponsored, and ugc; values are space-separated.

View Source shows server-delivered HTML; DevTools Elements shows the current DOM, which JavaScript may have changed. This checker does not execute page JavaScript, so links inserted only after rendering may not appear.

Page-level robots directives

The checker detects nofollow or none in HTML meta name="robots" and meta name="googlebot" directives and shows a separate warning. It does not inspect the HTTP X-Robots-Tag response header, so a directive supplied only through that header is not detected. Page-level directives and individual anchor rel values are different checks.

Common mistakes

  • Assuming “dofollow” is an explicit rel value; it means none of the qualifying values above were found.
  • Confusing page-level robots directives with anchor-level rel attributes.
  • Treating dofollow as a guarantee of SEO value or rankings.
  • Expecting JavaScript-injected links to appear in a server-HTML checker.
  • Calling every external link a backlink; confirm the destination host.

Frequently asked questions

What is a nofollow link checker?

A nofollow link checker inspects links in a page's returned HTML and identifies anchors whose rel attribute contains nofollow. This tool checks up to 10 public pages per run and also classifies sponsored, UGC, and dofollow links.

Is there a dofollow link checker online?

Yes. Enter up to 10 public page URLs to inspect returned HTML, review rel attributes, filter internal or external links, optionally match a target domain, and export results as CSV.

How do I check if a backlink is dofollow?

Enter the page containing the backlink and optionally enter your target domain. Find the row for your destination URL and inspect Type. A dofollow result means the anchor's rel attribute contains none of nofollow, sponsored, or ugc in the HTML inspected by the tool.

What is the difference between nofollow, sponsored, and UGC?

Nofollow is a hint that a publisher does not want to endorse or associate itself with a linked page. Sponsored identifies links created as advertisements, sponsorships, or other paid placements. UGC identifies links within user-generated content, such as comments or forum posts. These rel values are hints for search engines, not ranking guarantees.

Important limitations

Only public HTTP and HTTPS pages are supported. The checker does not execute page JavaScript; it inspects the HTML returned by the server. Site access controls may prevent a page from being fetched.

Understanding link attribute results

The checker reports the link attributes found in the HTML returned by each page. A link without a qualifying rel value is labelled dofollow by this tool. Links carrying rel="nofollow", rel="sponsored", or rel="ugc" are identified separately because those values communicate different link contexts to search engines. The scope column distinguishes internal links from external links, and the optional target-domain field narrows the results to links pointing to a domain and its subdomains.

These labels describe the markup observed, not a promise about ranking impact. Search engines decide how to interpret link signals, and a dofollow label does not guarantee crawling, indexing, ranking benefit, or that a backlink will be counted. The checker reads server-returned HTML rather than executing page JavaScript, so links injected only after client-side rendering may not appear. If a page blocks automated requests, use the local HTML fallback when available.

A common mistake

Do not treat every external link as a backlink to your target. Confirm the destination host, and remember that a page-level robots nofollow directive is separate from each anchor's rel attribute.
