Dofollow means the link's rel attribute contains none of nofollow, sponsored, or ugc. A robots nofollow directive is reported separately and does not rewrite individual link labels.

Pages that block automated requests or fail to load can be checked by pasting their HTML into the row's local fallback. Pasted HTML is parsed in your browser and is not sent to the Worker.

What do dofollow, nofollow, sponsored and UGC mean?

Links can carry a rel attribute that describes the relationship between the linking page and the destination. A dofollow link is the common shorthand for an ordinary link whose rel value does not include nofollow, sponsored, or ugc. There is no special rel="dofollow" value required in HTML. In this checker, dofollow is a classification based on the absence of those three values in the anchor markup it reads.

Nofollow (rel="nofollow") is a hint that the publisher does not want to imply endorsement or pass the usual link association. Sponsored (rel="sponsored") identifies links created as part of advertising, sponsorship, or another paid arrangement. UGC (rel="ugc") identifies links within user-generated content, such as forum posts or comments. More than one value can appear in the same rel attribute. These are hints for search engines; none guarantees a particular crawling, indexing, or ranking outcome.

These labels describe the markup found, not the quality of the destination or the value of a backlink. A dofollow classification does not guarantee that a search engine will crawl the link, count it, or use it as a ranking signal.

How to read the results

Each row represents a link found in the HTML returned for one of your submitted pages. The Page URL identifies the source page; Anchor shows its text (or image alt text); Link URL is the destination; Type shows the detected rel classification; and Scope marks the link as internal or external relative to the source page. Use the optional target domain to narrow results to that domain and its subdomains. The checkboxes, search field, and scope selector filter the displayed rows, and Download CSV exports the results.

The page status and link count summarize what the checker could fetch and parse. A robots nofollow warning is separate from the Type column: it indicates a detected page-level robots directive, not that every anchor has a nofollow rel value. If a page cannot be fetched, the row offers a local HTML fallback where you can paste its source for browser-side parsing.

Manual method: inspect a link yourself

You can verify a link without this tool. Open the source page in a browser, right-click near the link, and choose Inspect to open DevTools. Select the anchor element and examine its rel attribute. You can also use View Page Source and search for the destination URL or rel=. Look for tokens such as nofollow, sponsored, and ugc; the attribute may contain multiple space-separated values.

View Source shows the HTML delivered by the server. DevTools Elements shows the current DOM, which may have been changed by JavaScript after page load. This checker fetches server-returned HTML and does not execute page JavaScript, so a link inserted only after rendering may appear in DevTools but not in its results.

Page-level robots directives

This checker detects nofollow or none in HTML meta name="robots" and meta name="googlebot" directives and displays a separate warning. It does not inspect the HTTP X-Robots-Tag response header, so it cannot report a nofollow directive supplied only through that header. A page-level directive is different from an individual anchor's rel value; do not treat the warning as a per-link classification.

Common mistakes to avoid

  • Assuming that “dofollow” is an explicit HTML rel value. It is a common label for a link without the qualifying values above.
  • Confusing page-level robots directives with anchor-level rel attributes. They apply at different scopes.
  • Assuming a dofollow link guarantees SEO benefit, indexing, or rankings. The checker reports markup only.
  • Expecting JavaScript-injected links to appear. This tool does not execute page scripts.
  • Calling every external link a backlink to your site. Check the actual destination host and use the target-domain filter.
  • Assuming the absence of a warning proves every crawler can access the page. Fetch restrictions and browser rendering can affect what is visible.

Frequently asked questions

What is a nofollow link checker?

A nofollow link checker inspects links in a page's returned HTML and identifies anchors whose rel attribute contains nofollow. This tool checks up to 10 public pages per run and also classifies sponsored, UGC, and dofollow links.

Is there a dofollow link checker online?

Yes. Enter up to 10 public page URLs in this online checker to inspect their returned HTML, review link rel attributes, filter internal or external links, optionally match a target domain, and export the results as CSV.

How do I check if a backlink is dofollow?

Enter the page containing the backlink and optionally enter your target domain. Find the row for your destination URL and inspect its Type. A dofollow result means the anchor's rel attribute contains none of nofollow, sponsored, or ugc in the HTML inspected by the tool.

What is the difference between nofollow, sponsored, and UGC?

Nofollow is a hint that a site does not want to endorse or associate itself with a linked page. Sponsored identifies links created as advertisements, sponsorships, or other paid placements. UGC identifies links within user-generated content, such as comments or forum posts. These rel values are hints for search engines, not guarantees about ranking outcomes.

Vet link prospects: check DR, then check link attributes

When reviewing a potential backlink source, first use the Bulk DR checker to compare the site's Domain Rating with relevant prospects. Then use this link attribute checker to inspect the actual links on the page. DR is a site-level Ahrefs metric; the rel classification is page/link markup. Neither alone establishes link quality or a ranking outcome.

Important limitations

Only public HTTP and HTTPS pages are supported. The checker does not execute page JavaScript; it inspects the HTML returned by the server. Site access controls may prevent a page from being fetched.

Understanding link attribute results

The checker reports the link attributes found in the HTML returned by each page. A link without a qualifying rel value is labelled dofollow by this tool. Links carrying rel="nofollow", rel="sponsored", or rel="ugc" are identified separately because those values communicate different link contexts to search engines. The scope column distinguishes internal links from external links, and the optional target-domain field narrows the results to links pointing to a domain and its subdomains.

These labels describe the markup observed, not a promise about ranking impact. Search engines decide how to interpret link signals, and a dofollow label does not guarantee crawling, indexing, ranking benefit, or that a backlink will be counted. The checker reads server-returned HTML rather than executing page JavaScript, so links injected only after client-side rendering may not appear. If a page blocks automated requests, use the local HTML fallback when available.

A common mistake

Do not treat every external link as a backlink to your target. Confirm the destination host, and remember that a page-level robots nofollow directive is separate from each anchor's rel attribute.
