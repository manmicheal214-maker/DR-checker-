Title & meta description length checker

Measure characters and approximate search-result pixel width locally in your browser.

What is a title and meta length checker?

It measures title and description character counts and estimates their rendered pixel widths so you can review common SEO length signals before publishing.

Why check title and description length?

Very long snippets may be truncated in search results. Character counts are a useful starting point, while pixel width helps account for the fact that different characters occupy different amounts of horizontal space.

How it works

Everything runs locally in your browser. The tool uses Canvas text measurement with 20px Arial and compares the result with approximate desktop SERP widths: about 580px for titles and about 920–1000px for descriptions. These are industry estimates, not fixed Google limits, and can change over time.

Frequently asked questions

What length should an SEO title be?

A commonly cited working range is around 50–60 characters, but search result truncation varies and pixel width is also important.

What length should a meta description be?

A commonly cited working range is around 150–160 characters, but search result truncation varies by query, device, and rendering.

Are the pixel limits exact?

No. The checker uses browser Canvas measurements and approximate industry-estimated widths because Google does not publish a fixed pixel cutoff and the display can change over time.
