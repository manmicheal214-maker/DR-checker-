Meta preview

Inspect search and social metadata before you publish or audit a page.

Reading page metadata

What does a meta preview do?

A meta preview surfaces the HTML signals that commonly describe a page to search engines and social platforms: title, description, canonical URL, Open Graph fields, Twitter fields, robots directives, and the number of H1 elements.

Why and when to use it

Use it during SEO audits, launches, migrations, and content reviews to spot missing or inconsistent metadata. A preview is especially useful when the page source is difficult to inspect quickly across several URLs.

How it works

The tool makes a read-only HTTP request, validates the target hostname and each redirect, then reads at most 300 KB of the response body. It parses metadata with lightweight patterns and never executes JavaScript from the target page.

Frequently asked questions

What is a meta preview?

A meta preview shows the title, description, canonical URL, social metadata, robots directive, and H1 count detected near the top of a fetched HTML document.

Does this tool change my page?

No. It makes a read-only request and parses the returned HTML. It does not execute scripts or modify the target site.

How many URLs can I check?

Up to 8 URLs can be checked per request, with a 50-subrequest Worker budget shared across the batch.
