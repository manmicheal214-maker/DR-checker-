Hreflang tag generator

Build one complete hreflang block to place in the head of every page in a multilingual or regional page group.

Generated tags

Use this identical complete block on every page in the group, including the page's self-reference.

Why hreflang needs a complete set

Hreflang works as a reciprocal group. Every page in the set should contain the exact same full collection of alternate tags, listing every language or regional version and including a self-reference. This generator creates one block from all rows; do not create a different subset for each page.

Language and region codes

Enter a two-letter language code such as en, or a language plus uppercase region such as en-US. The special x-default value is also accepted. URL existence is not checked because this tool is fully client-side.

Frequently asked questions

Should each page have the same hreflang set?

Yes. Use the identical complete tag block on every page in the group, including each page's self-reference.

What is x-default?

x-default identifies the URL intended when no other language or regional variant is appropriate.

Does this validate that every URL exists?

No. It validates the code format loosely and does not make network requests.
