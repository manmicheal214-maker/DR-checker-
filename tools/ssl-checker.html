SSL certificate checker

Inspect recent certificate records from public Certificate Transparency logs.

Querying Certificate Transparency logs

What is an SSL certificate checker?

This tool looks up certificates recorded in public Certificate Transparency logs through crt.sh and selects the certificate entry with the most recent not-before date.

Why check certificates?

Certificate records can help with expiry reviews, inventory work, and spotting recently logged certificates for a domain.

How it works

The checker validates each domain and queries the fixed crt.sh Certificate Transparency service. It does not perform a live TLS handshake, so its result can differ from the certificate a server is presenting right now.

Frequently asked questions

What does this SSL checker inspect?

It looks up certificates for a domain in public Certificate Transparency logs through crt.sh and selects the entry with the most recent not-before date.

Does it perform a live TLS handshake?

No. Certificate Transparency data is often useful for understanding certificates associated with a domain, but it is not guaranteed to be identical to the certificate a server is presenting right now.

What happens if no certificates are found?

The tool returns a clear no-certificates-found message for that domain instead of failing the whole batch.
