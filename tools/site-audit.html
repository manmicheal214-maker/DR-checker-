    What this audit checks

    The report combines existing Worker endpoints for page metadata, response security headers, HTTP status, and broken links. Each check can fail independently; available results are still shown.

    Frequently asked questions

    How many pages are checked?

    This tool checks one page. For sitemap-based multi-page checks, use the domain-wide audit.

    How many links are checked?

    The broken-link check tests up to 15 distinct links from the page, subject to the endpoint's own hourly limit and subrequest budget.
