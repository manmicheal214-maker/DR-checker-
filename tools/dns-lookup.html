DNS lookup

Query common DNS record types for multiple domains in one pass.

Querying DNS

What are DNS records?

DNS records publish information that helps systems locate services for a domain. A and AAAA records map names to IPv4 and IPv6 addresses; MX records identify mail servers; NS records identify authoritative name servers; and TXT records carry text used for verification and other configuration.

Why and when to use DNS lookup

Use DNS lookups when troubleshooting a domain, checking mail routing, validating a migration, reviewing nameserver configuration, or confirming that verification records are published.

How it works

The tool sends fixed, trusted DNS-over-HTTPS queries to Cloudflare's resolver. You can select A, AAAA, MX, TXT, and NS records, with a maximum of 40 domain/type lookups per request. ANY queries are intentionally excluded.

Frequently asked questions

What are DNS records?

DNS records publish information that helps systems locate services for a domain, such as web servers, mail servers, authoritative name servers, and text records.

Which record types are supported?

This tool supports A, AAAA, MX, TXT, and NS records. ANY queries are intentionally not supported.

How many DNS lookups can I run?

Each request can contain at most 40 domain/type lookups. The tool also runs up to five DNS requests concurrently.
