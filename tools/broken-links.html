Broken link checker

Find a capped set of links on one page and test whether their destinations respond.

Checking links

What is a broken link checker?

A broken link checker fetches one page, finds its HTTP and HTTPS anchor links, and tests a capped set of destinations for reachable responses and redirect behavior.

Why check links?

Broken or unexpected links can frustrate visitors and make technical audits harder. Checking a page's links helps surface destinations that return errors, redirects, or cannot be reached.

How it works

The Worker validates the page and each destination against private-address protections, reads up to 500 KB of HTML, deduplicates links, and checks at most 15 destinations with a shared subrequest budget.

Frequently asked questions

What does a broken link checker do?

It fetches a page, extracts its HTTP and HTTPS links, and tests a capped set of those destinations.

How many links are checked?

The tool checks at most 15 distinct HTTP or HTTPS links per request and reports how many were found before the cap.

Does it follow redirects?

Yes. Each checked link follows up to two redirects and reports the final HTTP status.
