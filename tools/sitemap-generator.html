XML sitemap generator

Turn one absolute URL per line into a standards-shaped sitemap and download it without sending the list to a server.

What does an XML sitemap generator do?

This tool turns absolute URLs into an XML sitemap with one global change frequency, priority, and last-modified date. Validation happens locally, and invalid lines are reported rather than silently discarded.

URLs are XML-escaped before they are inserted into the document. That is especially important for query strings, where an ampersand such as & must become &amp; in the XML output.

Sitemap limits

A single sitemap file can contain at most 50,000 URLs. If your valid URL count exceeds that limit, this tool warns you to split the URLs across multiple sitemaps and create a sitemap index.

Frequently asked questions

What URLs can I enter?

Each line must begin with http:// or https:// and must be accepted by the browser URL parser.

Why is my ampersand changed to &?

XML requires special characters such as ampersands to be escaped. A URL such as https://example.com/?a=1&b=2 is therefore written with &amp; in the XML document.

What happens above 50,000 URLs?

The sitemap protocol limits a single sitemap file to 50,000 URLs, so a larger set needs multiple sitemap files and a sitemap index.
