How it works

What CheckDR measures, how the DR check is delivered, and where the metric has limits.

What happens when you run a DR check?

Rate limit: 10 checks per hour per IP.

You enter up to 100 domains or URLs. The browser sends those normalized domains to the CheckDR backend, which retrieves Domain Rating data through Ahrefs' public Domain Rating API and returns the results for display. CheckDR does not calculate the DR score itself.

The result table is a snapshot of the data returned when you run the check. The page also records a client-side “Checked” timestamp so you can tell when that result set was displayed. Each check requests the current value from Ahrefs at the time you run it. Values may differ from what you see inside Ahrefs.

What Domain Rating measures

DR is an Ahrefs metric on a 0–100 logarithmic scale intended to estimate the relative strength of a site's backlink profile within Ahrefs' index. Because the scale is logarithmic, moving upward at higher DR levels generally represents a larger increase in the underlying relative strength than an equal-looking move at the low end.

A higher DR does not mean better content, higher legitimacy, or a more trustworthy organization. It is a backlink-profile metric, not a general quality score.

DR is not a Google ranking signal

Domain Rating is an Ahrefs metric. It is not a Google ranking signal, and a DR number should not be treated as a direct prediction of search rankings.

Why numbers can differ between tools

Different SEO tools can have different indexes, crawl coverage, update schedules, formulas, and methodologies. As a result, authority-style numbers from different sources will not always match. Compare like with like when using a metric for a repeated workflow.

Frequently asked questions

What is DR?

DR is Ahrefs' Domain Rating metric, a logarithmic 0–100 estimate of relative backlink-profile strength within Ahrefs' index.

How is DR calculated?

CheckDR does not calculate DR. It retrieves the metric from Ahrefs' public Domain Rating API.

Does CheckDR need an Ahrefs account, API key, or login?

No. Visitors only enter domains; no Ahrefs account, login, API key, or other credentials are required.

Does CheckDR store the domains I check?

No. Submitted domains are not written to a database. Temporary IP-based request counters are used for hourly rate limiting.

Is CheckDR affiliated with Ahrefs?

CheckDR retrieves Domain Rating data through Ahrefs' public API. No. CheckDR is an independent tool and is not affiliated with, endorsed by, or sponsored by Ahrefs. Domain Rating data is retrieved through Ahrefs' publicly available Domain Rating data.

How often does DR change?

DR can change as Ahrefs' backlink index and its calculations change. There is no fixed interval at which every domain must change.

Why might two SEO tools show different numbers?

Different tools can use different indexes, datasets, update schedules, and methodologies, so their authority-style numbers may not match.

Does a high DR mean a site is trustworthy?

No. DR measures backlink-profile strength within Ahrefs' system; it is not a general trust, legitimacy, or content-quality score.

Can I check multiple domains at once?

Yes. The bulk checker accepts up to 100 domains or URLs per check.

Is CheckDR free?

Yes. The public checker is free, subject to fair-use rate limits.
