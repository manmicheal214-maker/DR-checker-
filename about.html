About CheckDR

A focused set of SEO utilities for quick, practical checks.

What CheckDR is

CheckDR is a lightweight SEO tool site built around a bulk Domain Rating checker and a growing collection of focused technical and content utilities. The tools are designed to make common checks easier to run without requiring an account.

What it does and doesn't do

The DR checker retrieves and displays Domain Rating data supplied through Ahrefs' public Domain Rating API; CheckDR does not calculate Domain Rating itself. The other tools cover tasks such as redirects, metadata, DNS, security headers, SSL, content readability, structured data, sitemaps, robots.txt, social previews, hreflang, and keyword clustering.

Tools can be useful signals for an audit, but they do not replace judgment, site-specific investigation, or authoritative documentation from the systems being checked.
