Privacy Policy

What CheckDR processes, what it does not store, and which analytics providers operate on the site.

What the tools receive

The site does not require an account, login, API key, or credentials for Ahrefs, Google, hosting, FTP, analytics, or any other account. Depending on the tool, visitors can submit domains, URLs, or keywords for processing.

Submitted domains, URLs, and keywords are not written to a database. There is no database in this stack.

Rate-limit information

For tools that use the backend, an IP address is used to enforce hourly rate limits. The Cloudflare value is a request count keyed for the relevant IP, tool, and hourly window. It does not contain the domain, URL, or keyword that was checked.

Those rate-limit counters automatically expire after roughly one hour. They are not sold, shared, or used for another purpose by CheckDR.

Analytics providers and information collected

CheckDR loads Google Tag Manager and Ahrefs Web Analytics only after a visitor selects Accept analytics. Neither analytics script is requested before acceptance. Selecting Reject prevents either service from loading.

Google Analytics through Google Tag Manager

Google Tag Manager (container GTM-PP972P5P) loads tags. CheckDR does not load a separate, hard-coded Google Analytics script. Google Analytics 4 is intended to run as a tag configured inside this GTM container. When configured and fired, Google Analytics can collect page views, site interactions, page/referrer information, approximate location, and browser/device information. The precise events and any additional tags depend on the live GTM container configuration.

GTM itself is a tag manager, not the analytics service. A GA4 tag commonly uses first-party cookies _ga and _ga_* for browser identification and analytics state. Other tags configured in GTM may set additional cookies; the repository cannot establish the full list without inspecting the live container.

Ahrefs Web Analytics

After acceptance, CheckDR loads Ahrefs Web Analytics from analytics.ahrefs.com using the existing project key. Ahrefs collects page URLs (including URL parameters), referrers, user-agent information used to report browser/device/operating-system details, country/city-level location, language preferences, and screen size. It automatically measures common interactions such as page views, link clicks, and form submissions. Ahrefs derives a daily pseudonymous visitor ID from IP address and user-agent data; it says raw IP addresses are discarded, the identifier is not used to track visitors across days, and it does not track people across devices or sites.

Ahrefs Web Analytics states that it uses no cookies or persistent identifiers. Therefore it is not expected to set analytics cookies. Google Analytics cookies may be set if/when a GA4 tag in GTM is configured and runs. The consent choice is stored in this browser's local storage under checkdr-analytics-consent, not in an analytics cookie.

Provider details: Google Analytics data collection, Ahrefs Web Analytics data collection, Google's Privacy Policy, and Ahrefs' Privacy Policy.

Cloudflare Web Analytics

Cloudflare Web Analytics provides basic traffic statistics independently of the optional Google Analytics and Ahrefs Web Analytics consent choice. It is designed to measure page views and aggregate site traffic without cookies or persistent visitor identifiers. Cloudflare's beacon can process page URL, referrer, browser and device information, and network information used to derive coarse geographic statistics. It is not gated by the cookie banner.

Cloudflare Turnstile

CheckDR uses Cloudflare Turnstile on protected forms or requests to distinguish legitimate visitors from automated abuse. Turnstile evaluates browser and device signals, request metadata such as IP address and user agent, and interaction/challenge signals to produce a verification result. This security check is separate from optional analytics consent and may run when a protected feature is used. Cloudflare processes this information to detect bots and protect the service.

Changing or withdrawing consent

Select Cookie settings in the footer to review or change your current choice. Opening settings does not change or withdraw consent. Close or press Escape to dismiss the banner while keeping your existing choice. Select Accept analytics to enable Google Analytics through Google Tag Manager and Ahrefs Web Analytics; this grants only the analytics_storage consent signal. Advertising-related consent signals remain denied. Select Reject to deny analytics consent and prevent the optional analytics scripts from loading on subsequent page loads.

If Google Tag Manager or Ahrefs Web Analytics has already loaded in the current page, choosing Reject updates consent, clears known Google Analytics/advertising cookies where possible, and reloads the page because already-running third-party scripts cannot be reliably unloaded in place. Your choice is stored in this browser's local storage. Cloudflare Web Analytics traffic statistics and Cloudflare Turnstile security checks are not controlled by this optional analytics setting. Clearing site data or using another browser/device resets the saved choice.

Third-party sharing

CheckDR does not sell or share the temporary rate-limit data with third parties. The disclosed exception is that Google Analytics and Ahrefs Analytics process their own visitor/usage data when their scripts run on the site, subject to their respective privacy practices.

Domain Rating data

Domain Rating data comes from Ahrefs' public Domain Rating API. CheckDR retrieves and displays that metric; it does not calculate Domain Rating itself.

Changes to this policy
